# Gerador de Senhas

Projeto simples desenvolvido em **HTML e JavaScript** para uma atividade da disciplina de DevOps.

## Funcionalidades

- Gerar senha aleatória
- Definir o tamanho da senha
- Incluir letras maiúsculas
- Incluir números 
- Incluir símbolos
- Copiar a senha para a área de transferência

## Tecnologias

- HTML5
- JavaScript
- CSS

## Como executar

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` no navegador.

Não é necessário instalar nenhuma dependência.

## Estrutura

```text
gerador-senhas-devops/
├── index.html
├── script.js
└── README.md
```

## Objetivo

O objetivo deste projeto é praticar conceitos básicos de versionamento de código com Git e GitHub durante as aulas de DevOps.
